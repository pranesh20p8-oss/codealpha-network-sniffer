
# CodeAlpha - Task 2: Secure Coding Review

## Objective
Review a Python login application to identify and fix
common security vulnerabilities.

## Tools Used
- Python
- Visual Studio Code
- Bandit

## Project Files
- login.py - Python login application
- security_report_after.txt - Bandit scan report
- .gitignore - Excludes local account data

## Security Improvements
- Password hashing and salting
- Login attempt limits
- Password validation
- Automated security scanning

## Conclusion
This project demonstrates how secure coding practices
and automated analysis can help improve application security.
